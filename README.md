# Optimization Techniques

MATLAB implementations of numerical optimization algorithms developed for the Optimization Techniques course at the Department of Electrical and Computer Engineering, Aristotle University of Thessaloniki (AUTH).

## Laboratory Assignments

### Assignment 1 – One-Dimensional Optimization
- Dichotomous Search
- Golden Section Search
- Fibonacci Search
- Derivative-Based Bisection

### Assignment 2 – Unconstrained Optimization
- Steepest Descent
- Newton's Method
- Levenberg–Marquardt
- Armijo Rule and Line Search

### Assignment 3 – Constrained Optimization
- Steepest Descent
- Projected Gradient Descent
- Box-Constrained Optimization
- Convergence and Numerical Stability Analysis

## Technologies

- MATLAB
- Symbolic Math Toolbox
